PURPOSE
Replace blind trust in six caller-supplied proposal-file digest claims with a bounded,
read-only observation of the current files, while preserving the hard boundary against
module import, candidate execution, workspace mutation, registry mutation, activation,
promotion, or canon change.

ARCHITECTURE
The new bounded-python-recipe-evidence-observer-hand.js:
- accepts one explicit absolute workspace root;
- reads exactly six declared relative paths and performs no directory scan;
- refuses filesystem roots, aliases, traversal, duplicate paths, symlinks in any path
  component, non-regular files, invalid UTF-8, byte drift, oversize inputs, digest drift,
  duplicated evidence digests, and proposal-core digest mismatch;
- hashes the current bytes of author source/contract, verifier source/contract, parameter
  contract, and adversarial-test receipt;
- binds author source to builderSha256, verifier source to verifierRunnerSha256, and the
  parameter contract to recipeSha256;
- parses two CommonJS JavaScript sources with vm.Script but never runs them;
- parses four JSON objects;
- emits a five-minute, digest-bound observation receipt.

The v1.1 admission plane now requires that live receipt. It independently validates the
receipt digest, lifetime, authority boundary, six-file set, proposal/evidence bindings,
and observed digests before it stages a descriptor. Admission itself still performs no
workspace read and has no execution, mutation, selection, authorization, or promotion API.

TRUTH BOUNDARY
This upgrade proves that six exact declared files existed, their current bytes matched the
claimed digests, their JavaScript/JSON syntax parsed without import, and three proposal-core
digests matched the observed artifacts. It does not prove the caller's test claims, source
semantics, runtime safety, authorship, identity, consent, human review, or registry fitness.
Parsing is not executing, and a digest is not a signature.
